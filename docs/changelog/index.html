Changelog

What changed in each version of Duo Clone, newest first. Dates are in GMT+7. For the reasoning behind some of these fixes, read the note on Android 15 and 16.

0.1.37Build 40
25 November 2026

Version 0.1.37 (build 40)

  • A copy with a lot of data now backs up. Backups are written in pieces, so a copy of a few hundred megabytes no longer fails, and restore reads the file straight from where you saved it. Backup files from earlier versions still restore.
  • When the phone or the folder you picked is out of space, a backup or restore now says Not enough free storage for the backup and tells you to free some space and try again.

0.1.36Build 39
24 November 2026

Version 0.1.36 (build 39)

  • Backing up a single copy now saves its data after you pick the save location. Before, the file could come out empty.
  • In the Google Play version, Incognito mode disguises Duo Clone as Toolbox, Planner or Shapes with plain icons, and the switch now works there. The APK build that XLAB distributes outside Google Play keeps Calculator, Weather and Notes.
  • With the Neutral notification switch on, the running notification shows Duo Clone without the number of clones, and it stays hidden on the lock screen.
  • Duo Clone's own background services now declare the kind of work they do, as Android 14 and later require: keeping copies running and receiving push messages are declared as special use, and backup and restore as data sync.
  • The Google Play version no longer declares permissions that copies never needed, such as payment, companion-device and system-settings permissions.

0.1.35Build 38
21 November 2026

Version 0.1.35 (build 38)

  • Sign in with Google now works inside a copy. Duo Clone shows a list titled Choose a Google account with the Google accounts of that Account and an Add another account row.

0.1.34Build 37
21 November 2026

Version 0.1.34 (build 37)

  • Tap the clone badge to open a small menu. It shows the clone's name and Account, then Open Duo Clone, Close clone and Hide badge. Hide badge removes the mark until you open the clone again.

0.1.33Build 36
21 November 2026

Version 0.1.33 (build 36)

  • A new switch in Settings, Notifications from closed clones, is off by default. When it is on, Duo Clone keeps one silent notification and apps in your copies receive their messages while they are closed. It uses some extra battery.
  • Notifications from a copy now carry the clone's name and number: the header reads Duo Clone, then the app and Clone #1, and the clone's name comes before the title.
  • Apps in copies can now receive push messages while they run and run their scheduled background work, which apps use for notifications and sync.
  • Apps that start part of themselves in a separate process, such as a chat app's widget engine, no longer close when you open them in a copy.
  • Sign-in flows that pass through a web page, as in some social apps, now come back to the copy instead of leaving it, and apps that wait for background work to end finish it the way Android does, so logging out no longer hangs.
  • Passwords an app offers to save in a copy are kept for that copy only, encrypted, and offered back with a Sign in with a saved login? prompt. Passkeys do not work in copies, and Duo Clone says so when you start one.
  • The dimmed clone badge is easier to see: it fades to 60 percent instead of 35 percent and has a white outline and a shadow.

0.1.32Build 35
21 November 2026

Version 0.1.32 (build 35)

  • Fingerprint and face prompts now work inside copies of apps that use them. Before, the prompt never appeared in a copy.
  • Clear data, in the copy's menu next to Delete clone, resets one copy to like new after you confirm. The copy, its name, icon and lock stay, and so does the shared Google account of the Account. Logins inside the copy are removed.

0.1.31Build 34
21 November 2026

Version 0.1.31 (build 34)

  • Tablets and phones without a SIM card, a camera or other optional hardware can now install Duo Clone from Google Play. Those hardware features are no longer marked as required.

0.1.30Build 33
21 November 2026

Version 0.1.30 (build 33)

  • If Duo Clone cannot check your Accounts online, for example right after you install it without a connection, it now uses the standard Account limit until it can check.

0.1.29Build 32
20 November 2026

Version 0.1.29 (build 32)

  • The Add account row on the By Account tab now shows how many Accounts you are using out of how many you have, for example 1/2.
  • When every Account is in use, the row turns into a card with a lock icon, the words Account limit reached and an Enter gift code button. The new clone sheet and the message after adding several apps use the same wording.

0.1.28Build 31
20 November 2026

Version 0.1.28 (build 31)

  • The Restart button for a downloaded update now always responds. If Google Play cannot install the update, the button opens the Duo Clone page on Google Play instead of doing nothing.

0.1.27Build 30
20 November 2026

Version 0.1.27 (build 30)

  • The clone badge is now a small rounded square in the clone's color. After you drag it, it moves to the nearer side of the screen and keeps clear of the system bars, the camera cutout and the gesture areas.
  • Tap the clone badge to see the clone's name for a moment; screen readers read the same name.
  • The badge name shows the copy number only once, so a clone called Chat #2 no longer reads as Chat #2 with a second #2 after it.
  • The missing permission notice appears once, instead of a dialog in Duo Clone followed by a short message with the same text.

0.1.26Build 29
20 November 2026

Version 0.1.26 (build 29)

  • Duo Clone shows its own icon on Android 6 and 7, instead of the plain Android robot.
  • On Android 8 to 14, the navigation bar now follows the dark mode you chose inside Duo Clone, not the phone's setting.
  • The missing permission notice shows even while Duo Clone is already open, and permission names always start with a capital letter.
  • Stop all now closes every running clone completely, without leaving an empty clone running in the background.
  • Vietnamese labels in the app picker and the new clone dialog are no longer cut off, and the text on green buttons is easier to read.

0.1.25Build 28
20 November 2026

Version 0.1.25 (build 28)

  • A new Add account row at the end of the By Account tab opens the app picker with the next new Account already selected.
  • The clone badge now docks on the left or right edge of the screen, keeps clear of the system bars and the camera cutout, and fades when you are not touching it.
  • Choosing a language inside the app applies it on the first tap, and notifications follow the language you chose.
  • The list and grid switch on My Clones is now an icon button; press and hold it to see its name.

0.1.24Build 27
20 November 2026

Version 0.1.24 (build 27)

  • The app now follows the Duo Clone look: paper and ink surfaces with green and pink accents. The Duo Clone mark and name appear in the header, the consent screen, About and the opening screen.
  • Pink marks the main actions (Agree, Add app, the + button, Create, Update), the active tab and selected chips. Green stays for status, Open and success.
  • New launcher icon, including a single-tone version for themed icons.
  • Classic green is still available as a color theme choice in Settings.
  • Dialogs read as paper, and the view mode tabs no longer cut off their labels.

0.1.23Build 26
20 November 2026

Version 0.1.23 (build 26)

  • New color theme choice in Settings, next to light and dark: Duo Clone or Classic green. It applies at once and is remembered.
  • Camera clones can save photos on Android 16 and 17.
  • Clones of system apps, such as Camera, now ask for camera, microphone, location and (on Android 9 and older) storage permission with the normal dialog before they open.
  • The missing permission notice now also shows when the Contacts app closes its permission screen. On Android 16 and 17 the notice comes back as a dialog with the clone's name when you return to Duo Clone. A private clone is not named while the private space is locked.
  • Fixed a freeze the first time a clone that uses Google sign-in opened on Android 16.
  • The search keyboard closes when the new clone dialog opens, messages in the app picker show above the keyboard, and the copy number stays in order next to right-to-left text.
  • Clearer messages from the update check.

0.1.22Build 25
20 November 2026

Version 0.1.22 (build 25)

  • Maintenance release with no changes you will notice.

0.1.21Build 24
20 November 2026

Version 0.1.21 (build 24)

  • Fixed connection errors on Android 6 and 7.0, so the app reaches its online features on those versions.
  • On Android 9 and older, a camera clone can now save a photo, and it stays open afterwards instead of closing about ten seconds later.
  • Fixed a clone that closed unexpectedly after the phone's language changed, in some apps.

0.1.20Build 23
20 November 2026

Version 0.1.20 (build 23)

  • The product name reads Duo Clone throughout the app, with more of its text translated into the 23 languages.
  • Typing in clones is smoother on Android 15 and 16: text fields no longer stall for a few seconds when you tap them, and the keyboard works with them.
  • Browsers based on Chromium now open and keep running inside clones instead of closing after about a minute.
  • Tapping a Protected app in the picker now tells you why it cannot be cloned.
  • The dialog for a second copy selects an account that is still unused.
  • The empty home button now reads Add app.
  • The clone badge and the quick-switch bubble no longer sit under the system bars.
  • The Contacts app in a clone no longer stays on a loading spinner on Android 16.
  • The missing permission notice also shows when a clone opens its App info page.
  • Fixed some clones that closed by themselves shortly after opening.
  • The app now tells you when a newer version is available, with the release notes.

0.1.19Build 22
19 November 2026

Version 0.1.19 (build 22)

  • Stopping a clone now stops it for good. Opening a clone that is already running brings it to the front instead of starting it again.
  • Clones of older apps no longer draw under the status bar and the navigation bar on Android 15 and later.
  • The app picker shows apps that cannot be cloned, such as Settings, Files and other Duo Clone builds, dimmed with a Protected badge.
  • When a clone asks for a permission that Duo Clone cannot grant, you now see one short notice instead of nothing.
  • The home header and the running notification show correct clone counts in every language, the picker search starts empty, and the new clone dialog opens without the keyboard.
