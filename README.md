# Duo Clone – official developer page

Duo Clone is an Android app cloner for running multiple accounts of the same app on one phone. This repository holds the developer's official page and the release notes.

- Developer page: https://xlabcompany.github.io/duoclone/
- Changelog: https://xlabcompany.github.io/duoclone/changelog/
- [Duo Clone website](https://duoclone.com/)

Google Play is the only official channel for Duo Clone; it is never offered as an APK.

Found a problem or have an idea? Open an issue in this repository.
